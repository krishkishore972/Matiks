# Gameplay notes (recovered rules + inferred maths)

Per-mode rules are quoted from the shipped bundle. Numeric cut-offs that are not
in the artifact are marked **(inferred)** and mirrored in `lib/scoring.ts`.

## Cross-cutting rules

- **Duel length:** 60 seconds, read as three 20-second windows. Blitz shapes
  (Dominator, Comeback, Clutch, Almost, Close Call / Slip up, Blunder, Crushed)
  come from how the lead moved across those windows.
- **Accuracy:** every wrong attempt, backspace, clear and retry counts. Accuracy
  is `correct / (correct + mistakes)`, so a clean run is the only way to 100%.
- **Minimum score:** a play only counts towards quests and streaks if it beats
  the mode minimum (table below).
- **Overtime:** if both sides finish a duel on the same score, an overtime
  tiebreaker decides it.
- **Streak trigger:** any of — play a duel, finish the Daily Challenge, join a
  contest. Shields cost 200 Pies and at most 2 can be held.
- **Rating:** Elo-style **(inferred K-curve)**.

## Daily Challenge

Board types: Sudoku, KenKen, Cross Math, Math Maze, Hectoc. Divisions: 1st
2000+, 2nd 1200+, 3rd 800+.

| Mode | Recovered rule | Implementation |
| --- | --- | --- |
| Sudoku | "Fill in the numbers so that no number repeats in any row, any column, or any box." | 9×9, uniquely solvable, generated by digging from a solved grid. |
| KenKen | "Heavily outlined areas called cages… a target number and a mathematical operation… numbers inside a cage must combine to equal the target… each number exactly once in each row and column. Order does not matter for subtraction and division." | Cages + clue labels rendered on the board; validation covers cages, rows and columns. |
| Cross Math | "Each row and column is a math equation… No BODMAS here — do calculations as you move, always left to right." | Equations evaluated left-to-right, never with precedence. |
| Math Maze | "Make a path: one cell per row, moving at most one column sideways." | Path must start on IN, end on OUT, one cell per row, ≤1 column of lateral movement. |
| Hectoc | "Use the six given digits in order to build an expression equal to 100… You may insert + − × ÷ and brackets anywhere." | Digits must be consumed in order, exactly once; answers are judged exactly with rational arithmetic, not floats. |

## Infinite ladder

| Mode | Recovered rule | Implementation |
| --- | --- | --- |
| Queens | "Queens can't touch, not even diagonally. Place one queen in every row, every column and every coloured region." | Regions generated with a unique solution under those constraints. |
| Tango | "Fill the grid so every row and column holds three of each symbol. No three identical symbols in a row… = and ≠ markers pin neighbouring cells." | 6×6, constraints rendered between cells, uniqueness verified. |
| Zip | "Draw one continuous path through every cell… Pass the numbered checkpoints in ascending order, starting at 1." | Hamiltonian path with ordered checkpoints; tap-to-extend, tap-back to backtrack. |
| Pipes | "Tap a tile to rotate it… No opening may point off the board or into a tile that doesn't open back… every tile must end up part of one connected network." | Leaks and component count shown live; a win route is built from the solution rotations. |
| Wend | "Drag adjacent letters to form a word. Keyboard: type the word, Backspace to backtrack, Enter to submit, Escape to clear." + "the word lengths shown are your only hint" | Words laid along winding adjacent paths; validated for contiguity and membership; only lengths are shown. |
| Patches, Flip Match | Named in the bundle; rules not recoverable. | Not shipped — listed as a known gap rather than invented. |

## Duels / reflex

| Mode | Recovered rule | Implementation |
| --- | --- | --- |
| Sprint | "In a 60-second sprint you play boards back to back. Your first board is board position 1, your second is position 2…" | 60s of arithmetic boards, typed answers. |
| Fastest Finger | "PLAY 1-MIN FASTEST FINGER DUEL… race to solve the most in 1 minute." | 60s, multiple-choice answers. |
| DMAS | "Solve DMAS problems at the top and enter your answer below. Difficulty scales with your rating." | Precedence-respecting expressions; level derived from rating. |
| Mind Snap | Presets `25G(9S)`; "Memorise and tap the correct pattern as fast as you can"; "Each correct tap +1, each wrong −1. You get only as many taps as highlighted tiles." | 5×5 / 9 tiles per board, 1.2s flash **(inferred)**, 60s of boards, cumulative points. |
| Flash Anzan | "Flash Anzan has 3 rounds of fast mental addition." | 3 rounds of 5 two-digit terms **(inferred: 10 points per term**, which reconciles with the min score of 90). |
| Pin Ball Recall | "Track the ball through the bumpers, then recall its exit… The bumpers auto-hide after 5 seconds. An exact exit is 1 point, an adjacent tap 0.5." | 5s reveal, 8 boards **(inferred board count)**, 1/0.5 scoring. |
| Ability Duels (Sum of Squares) | "Numbers when squared and added give the target number… can have multiple solutions… Use space to separate multiple numbers." | Any decomposition is accepted; overshoot is reported. |

## Scoring, bands and shapes **(inferred)**

- **Puzzle score:** `1000 × difficultyWeight × (0.5 + 0.5·accuracy) ×
  (0.7 + 0.3·speed)`, floored at 0 when unsolved. Weights: easy 1, medium 1.35,
  hard 1.75, expert 2.2.
- **Par times:** easy 90s, medium 150s, hard 240s, expert 360s.
- **Quality bands:** solve-time ratio to par — ≤0.5 ZAP, ≤0.9 FLOW, ≤1.4 GRIND,
  ≤2.2 CHOKE, else FREEZE.
- **XP:** `score/10 + 25` when solved, doubled while an XP Booster runs.
- **Levels:** level *n* costs 250·n XP.
